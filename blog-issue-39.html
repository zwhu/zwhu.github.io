Jest + Power-Assert 配置

2018-02-24 · 记录 · 原 issue #39 ↗

只是记录下安装过程和配置，也许你刚好会用到：

npm install --save-dev jest power-assert babel-preset-power-assert
// .babelrc
{
  "presets": [
    "power-assert"
  ]
}
// package.json
{
    "test": "jest"
}
npm test
