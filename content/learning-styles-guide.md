# 学习页样式与交互复用

适用于现有六篇 `learn-*.html`。视觉数值以 [视觉规范](../VISUAL_STYLE.md) 为准；本说明规定样式归属和接入方式。

## 样式放在哪里

| 文件 | 职责 |
| --- | --- |
| `style.css`、`archive.css` | 全站颜色、导航、基础文章布局和评论 |
| `learning.css` | 学习页标题、来源、目录、相关阅读、基础控件、代码和表格，以及焦点、隐藏状态、减少动态效果和打印约定 |
| `assets/learning/<主题>.css` | 本课程的内容布局、图示、实验、测验状态和响应式变化 |
| `assets/learning/<主题>.js` | 本课程已有交互行为 |

课程专用选择器放回课程文件，便于同时找到布局、状态和窄屏规则。公共文件只维护实际复用的基础，不再集中追加某篇课程的补丁。

页面外壳的宽度和左右边距复用 `style.css` 的 `--page-width` / `--page-padding`。`learning.css` 在 `.learning-page` 上设置 1080px 宽度，使页头、正文外壳与页脚保持对齐；标题、相关阅读和评论继续保留原有的内部阅读宽度。课程样式不单独修改外壳宽度。

现有课程的参考范围：

| 课程 | 可以参考的实现 |
| --- | --- |
| `aime-paper` | 两组标签切换、面板关联、原生审稿速览、架构示意图 |
| `llm-study` | 分阶段讲解、Attention 与概率实验、闪卡、可重新作答的测验 |
| `ai-coding-playbook` | 操作步骤、可展开提示词、复制失败后的手动复制入口 |
| `agent-memory` | 上一步／下一步、模块展开、自测反馈 |
| `pi-compaction` | 压缩步骤、场景切换、上下文条形和局部滚动图 |
| `react-token-accumulation` | SVG 演示的暂停、重播和完整结果 |

这些是现有实现的参考，不代表已经提供可跨页调用的全部交互模块。例如 `setupTabs` 当前只在 AIME 内服务两组切换。

## 接入约定与原因

1. **保持四层样式的加载顺序。** 先加载全站样式，再加载课程样式，最后加载学习页公共基础。公共基础在最后统一控件、阅读尺度和可访问性，避免导入布局重新引入另一套主题。

   ```html
   <link rel="stylesheet" href="./style.css">
   <link rel="stylesheet" href="./archive.css">
   <link rel="stylesheet" href="./assets/learning/agent-memory.css">
   <link rel="stylesheet" href="./learning.css">
   ```

2. **课程正文具有公共类和独立主题类。** 导航、文章标题与评论保留在正文外壳中。这样课程布局不会污染全站导航，公共控件也有明确的作用范围。

   ```html
   <div class="learning-content lesson-agent-memory">
     <!-- 课程正文与交互 -->
   </div>
   ```

3. **颜色直接使用全站语义变量。** 使用 `--bg`、`--text`、`--muted`、`--accent`、`--line`、`--code`，不要恢复旧主题的 `--ink`、`--paper`、`--green` 等别名，也不要给每个后代重置变量。这样更换一个全站颜色时不会留下同用途的旧色。

4. **同一状态的声明在课程文件内合并。** 先修改已有规则，再检查响应式和状态变化；避免在文件末尾继续覆盖。课程与公共控件确有差异时，可使用 `.learning-content.lesson-<主题>` 明确限定。例如 AIME 的文字下划线标签需要覆盖公共描边按钮。

5. **交互效果由真实状态表达。** 使用 `aria-selected`、`aria-pressed`、`aria-expanded`、`disabled` 等适用状态，并保留可见焦点。单独切换颜色不足以让键盘和读屏用户获得相同信息。

## 修改后的检查

运行 `python3 scripts/check-learning-styles.py` 检查样式归属、主题作用域、旧变量和加载顺序；这个检查不代替浏览器验收。

检查脚本自动发现根目录的 `learn-*.html`，新增课程也会纳入检查；每篇须有同名课程 CSS，逗号分隔的每个选择器都要限定作用域。

同一命令已接入 `.github/workflows/static-checks.yml`，在 PR 创建／更新、推送 `main` 及手动触发时，与公共生成、SEO 和评论检查一起运行。`main` 已启用 PR 与必需 `check` 门禁，要求分支保持最新，管理员也受约束；配置与验证见[CI 交接](./ci-handoff.md)。GitHub Pages 仍从 `main` 发布，通过检查的 PR 合并后更新网站。

- 在 375、560、700、1280px 检查六篇课程，关注换行、间距、局部滚动和文末相关阅读；响应式临界点附近也要检查。
- 涉及纯样式归位时，对照改动前后的最终布局和计算样式。测量时排除过渡动画中间帧，演示本身的动画另行验证。
- 实测本次触及的切换、展开、实验、闪卡、测验、复制与演示控制；确认焦点和选中状态可见。
- 检查减少动态效果和打印样式仍存在，正文、原图、来源与评论入口保留；实际没有执行的验收不得声称通过。
- 修改 HTML 后确认统计脚本每页一份、相对资源和锚点可用，并执行现有 SEO 检查。样式调整不改变文章日期、文件名或评论标识。
