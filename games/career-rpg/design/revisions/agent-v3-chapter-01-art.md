# 南京第一章：素材制作清单与规格

本章制作规格，只服务于 `nanjing-first-release`。下面所有尺寸与锚点都是**设计值**：尚未制作、导出或检查任何生产素材。概念板 `art/nanjing-art-direction-v1.png` 只用于看方向，既不是图集来源，也不代表作者已认可。ID、像素尺寸、占格与锚点与 [chapter-01.json](./chapter-01.json) 的 `assets`、`map.objects` 一致。

## 一、网格、坐标与锚点

- 逻辑像素：1 逻辑 px 显示为整数倍设备像素（2×、3×、4×），近邻采样，关闭线性过滤与 mipmap。地图地砖 16×16，角色帧 16×24。
- 坐标用像素索引：图左上角是 (0,0)，x 向右、y 向下；宽 16 的图最右列是 15，高 24 的图最下行是 23。锚点 (anchorX, anchorY) 是一个像素索引，必须落在尺寸范围内。
- **角色**：脚底锚点 (8,23)，即第 8 列、第 23 行像素。落点公式：脚底像素对齐到“所在格左上角 + (8, 16)”，即所在格最后一行像素（索引 15）的中间、横向第 8 列像素的中间。格内没有“第 16 行”。
- **家具**：锚点取贴图底边中央像素 (宽÷2−1, 高−1)，落点对齐到 footprint 最下方那一格的“左上角 + (8, 16)”。视觉包围可以叠到格子上方、横向超出格子；地面碰撞只看 footprint。例如书架 40×48、锚点 (19,47)，footprint [19,3]、[20,3]，落点在 y=3 格底边中央，贴图向上约 3 格、横向比两格多 8 px。
- 镜头：固定正交俯视三分之四视角，地面轴向排布。遮挡顺序按锚点所在格的行号排序，同一行再按 y、x。

## 五、DOM 中文与手机 UI

中文字不进位图：对话框、论坛、笔记本、手册、任务条、暂停菜单都用 HTML/CSS 系统字体，正文不小于 16 CSS px，行高 1.6；位图只负责底框、按钮底座和图标。

- 桌面：画布按 2× 或 3× 整数倍缩放，居中显示整张 24×16 地图，外层留对话区。
- 手机竖屏 375 CSS px：不缩放整张地图，逻辑视口改为跟随镜头的较小区域（例如 12×12 格），世界被裁切而像素仍按设备像素整数倍显示；镜头以角色为中心、按整格追随，边缘露出地图外背景。对话、任务条、方向键是独立 DOM 层，字号与 44 CSS px 触控热区不随像素倍率变化。
- 横屏时按钮缩短边距；横竖切换不丢状态，也不改变像素整数倍。
- 手机上的交互按钮只在满足“站在交互点且朝向正确”时才可点，不提供自动寻路。

## 六、音频

只记录时长与是否循环，没有像素尺寸。声音默认关闭。`audio-ui-click` 60 ms、`audio-ui-move` 40 ms、`audio-notebook-tick` 120 ms、`audio-manual-page` 300 ms、`audio-open-forum` 220 ms、`audio-step` 150 ms、`audio-transition-dim` 400 ms、`audio-ambient-office` 1500 ms（循环）。

## 七、图片与视频验收（要求，未执行）

- 像素：导出 1:1 原始尺寸 PNG，注明 CSS 视口与 DPR；放大查看不得有半透明或彩色杂边。
- 透明边缘：角色与家具贴边像素不得残留底色；图集帧之间没有渗色。
- 锚点：每帧脚底在 (8,23)；家具锚点在贴图底边中央，例如书架 (19,47)、桌子 (19,31)、保温杯 (5,11)。
- 图集尺寸：`player-walk` 每帧 16×24、整图 64×96；`npc-cto` 每帧 16×24、整图 16×96。
- 占格：贴图 40×32 的桌子视觉包围约 2.5 格，碰撞只占一格；截图时叠加 footprint 网格核对。
- 调色板：抽样像素全部来自 12 色，数量与文件一致。
- 墙窗只在地图外，实机截图中角色不会与画中的墙重叠。
- 必交截图：办公室全景、角色四向站立与行走、各家具贴图与占格对照、论坛／笔记本／手册、桌面与 375 px 手机、两小时转场前后。

视频：完整样章 2～3 分钟正常速度录屏、桌面交互片段、手机真机触控片段、异常恢复片段（连续点击、跳过、刷新继续、切后台）。截图与录屏都要标版本、浏览器、设备与输入方式；以上材料均尚未产生，不能写成已通过。
