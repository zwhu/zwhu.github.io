# 南京第一章：素材制作清单与规格

本章制作规格，只服务于 `nanjing-first-release`。所有尺寸为设计值，尚未制作或检查任何生产素材；概念板 `art/nanjing-art-direction-v1.png` 不作为图集来源，也不代表作者已认可。ID 与 [chapter-01.json](./chapter-01.json) 的 `assets` 一致。

## 一、统一网格与调色板

- 逻辑像素：1 逻辑 px = 整数倍屏幕像素；地图地砖 16×16，角色帧 16×24。Three.js 中整图近邻采样，关闭线性过滤与 mipmap 模糊。
- 锚点：角色与物件一律以脚底为 (anchorX, 高度−2) 像素落在 tile 下沿中央；镜头固定正交俯视三分之四，地面轴向排布。
- 调色板（同一张 16 色索引 PNG 调色板，所有素材共用）：暖白 `#faf8f3`、墨色 `#292825`、石灰 `#77746e`、朱砂红 `#a64335`、木深 `#6b4a32`、木浅 `#a87c55`、砖灰 `#8d8a83`、草绿 `#6f8f5a`、低饱和蓝灰 `#5d6e7a`、夜蓝灰 `#2f3a45`、窗光 `#e8dfc8`、暖光 `#e9c27a`。
- 光色离散化：只允许 2～3 档色阶，不画渐变、光晕和柔边；转场压暗另用夜蓝灰档。

## 三、四向行走帧

| 资产 | 帧 | 排布 | 播放 |
| --- | --- | --- | --- |

## 四、DOM 中文与手机 UI

中文字不进位图：对话框、论坛、笔记本、手册、任务条、暂停菜单都用 HTML/CSS 系统字体，正文 ≥16 CSS px，行高 1.6；位图只做底框与边框（见 UI 资产）。

- 桌面：画布居中，最大约 768×512 CSS px（24×16 格 × 2 倍），外层留对话区。
- 手机竖屏 375px：画布等比缩放，可滑动视口跟随人物；方向键与 A 按钮固定在底部两侧，单一热区 ≥44 CSS px，不与当前交互提示重叠；横屏时按钮缩短边距。
- `ui-mobile-controls` 只画底座，A 字母由字体渲染，避免小图糊字。

## 六、图片与视频验收（只列要求，未执行）

- 图像素：必须以 1:1 或整数倍导出，保留原始尺寸 PNG，旁边的文字注明 CSS 视口与 DPR；放大查看时不应出现半透明或彩色杂边。
- 透明边缘：角色与物件的贴边像素不得有残留底色或半透明像素；图集间距足够，相邻帧之间没有渗色。
- 帧对齐：四向站立帧脚底落在锚点 (8,24)，行走帧左右轮廓同高；连续播放不跳动、不漂移。
- 锚点：把样例物件放进 [19,2] 书架位与 [14,11] 保温杯位，确认视觉与地面占格分别正确，交互点 [19,3] 与 [14,10] 不被遮挡。
- 调色板：抽样像素全部来自统一 16 色调色板，不得另有抗锯齿产生的中间色。
- 必交截图：办公室全景与局部、对话框／论坛／手册、桌面与手机竖屏、两小时转场前后。

视频：完整样章 2～3 分钟正常速度录屏，桌面交互片段，手机真机触控片段，异常与恢复片段（连续点击、跳过、刷新继续、切后台）。截图与录屏都要标版本、浏览器、设备与输入方式；全部尚未产生，不能写成已通过。
