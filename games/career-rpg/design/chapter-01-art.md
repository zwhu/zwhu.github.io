# 南京第一章：素材制作清单与规格

本章制作规格，只服务于 `nanjing-first-release`。尺寸与锚点都是**设计值**：尚未制作、导出或检查任何生产素材。概念板 `art/nanjing-art-direction-v1.png` 只用于看方向，不是图集来源，也不代表作者已认可。ID、像素尺寸、占格与锚点与 [chapter-01.json](./chapter-01.json) 的 `assets`、`map.objects` 一致。

## 一、网格、坐标与锚点

- 逻辑像素 1 px 显示为整数倍设备像素（2×、3×、4×），近邻采样，关闭线性过滤与 mipmap。地砖 16×16，角色帧 16×24。
- 坐标用像素索引：图左上角 (0,0)，x 向右、y 向下；宽 16 的图最右列是 15，高 24 的图最下行是 23。锚点 (anchorX, anchorY) 是图内像素索引，必须落在尺寸范围内。
- 统一落点公式（角色与家具共用这一个）：格 (x,y) 上的落点 = 格左上 + (8,15) = 世界逻辑像素 (16*x+8, 16*y+15)；精灵内脚底索引 [8,23]。
- 家具：家具按 footprint 最下方一格的格索引 (x,y) 套同一个公式，落点 (16*x+8, 16*y+15)；贴图内锚点 (宽÷2−1, 高−1)，贴图与锚点以落点为对齐点。 例：书架 32×48，footprint [19,3]、[20,3]，最下方一格是 [19,3]，落点 (16*19+8, 16*3+15) = (312, 63)，贴图内锚点 (15,47)。
- 镜头：固定正交俯视三分之四视角，地面轴向排布；遮挡按锚点所在格的行号排序，同一行再按 y、x。

## 二、统一调色板（精确 12 色）

全部位图共用一张 12 色索引调色板，禁止抗锯齿半透明像素和表外颜色：

- `warm_white` `#faf8f3`
- `ink` `#292825`
- `stone` `#77746e`
- `cinnabar` `#a64335`
- `wood_dark` `#6b4a32`
- `wood_light` `#a87c55`

离散光色：日景一档光照；两小时转场用 `night_blue` 两档叠加压暗（`tile-outage-dim`）。不用渐变、光晕与柔边。

## 五、DOM 中文与手机 UI

中文字不进位图：对话框、论坛、笔记本、手册、任务条、暂停菜单都用 HTML/CSS 系统字体，正文不小于 16 CSS px，行高 1.6；位图只负责底框、按钮底座和图标。

- 桌面：画布按 2× 或 3× 整数倍缩放，居中显示整张 24×16 地图。
- 手机竖屏 375 CSS px：不缩小整张地图，逻辑视口改为跟随镜头的较小区域（例如 12×12 格），世界被裁切而像素仍按设备像素整数倍显示；镜头以角色为中心、按整格追随。对话、任务条、方向键是独立 DOM 层，字号与 44 CSS px 触控热区不随像素倍率变化。
- 横竖切换不丢状态，也不改变像素整数倍；交互按钮只在“站在交互点且朝向正确”时可点。

## 六、音频

只记录时长与是否循环，没有像素尺寸；声音默认关闭。`audio-ui-click` 60 ms、`audio-ui-move` 40 ms、`audio-notebook-tick` 120 ms、`audio-manual-page` 300 ms、`audio-open-forum` 220 ms、`audio-step` 150 ms、`audio-transition-dim` 400 ms、`audio-ambient-office` 1500 ms（循环）。

- 透明边缘：角色与家具贴边不得残留底色；图集帧之间没有渗色。

- 占格：贴图 40×32 的桌子视觉比一格宽，碰撞只占一格；两格宽书架贴图 32×48，碰撞恰好两格；截图时叠加 footprint 网格核对。

- 墙窗只在地图外，实机截图中角色不会与画中的墙重叠。
