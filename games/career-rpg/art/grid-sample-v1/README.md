# Grid Sample v1 (Career RPG 美术样本)

本目录是一次**探索性的像素网格样本**，用于审阅并讨论角色比例、方向视图与地砖表现。

- 角色与地砖矩阵为 **DeepSeek Flash 原创矩阵（人物可读性由 Codex 最终修订）**，存在 `source.json` 中；没有从概念图、截图或任何外部图片派生而来。
- 仅使用 12 色固定调色板（加一个透明项），生成过程无插值、无渐变、无随机数。
- 这是一次试验性样本，**尚未获得作者确认**，**也未经实际游戏玩法验证**（未做碰撞、寻路、动画时序等测试）。请勿视为最终美术资产。
- 四个站立方向：下、上、左、右；左右为独立帧，不做镜像相等断言。

## 输入

`source.json`

- `palette`：12 个不透明色 + `"."`（透明，RGBA `[0,0,0,0]`）。不透明色 alpha 均为 255 且 RGB 两两不同。
- `frames`：`down` / `up` / `left` / `right`，每个 24 行 × 16 列。
- `tile`：16 行 × 16 列地砖。
- `meta.grid.anchor`：[8, 23]，为两只鞋与身体 4-连通的像素，视为脚点锚。

## 输出

- `player.png`：16×24 帧竖直堆叠，顺序 down/up/left/right，共 16×96。
- `floor.png`：16×16 不透明地砖。
- `preview.png`：左侧 8× 放大的四方向视图；右侧 8×4 地砖地面，并放置 `down`、`right` 两个站立角色。
- `verification.json`：实际输出尺寸、SHA-256 哈希、已执行检查项与放置坐标。

## 坐标约定

- 帧脚点：`[AX, AY] = [8, 23]`，与地砖格脚点 `[8, 15]` 对齐。
- 地砖网格原点 `(gx, gy)`，角色所在格 `(col, row)`：
  - 角色画布原点：`fx = gx + col*16*8 + 8*8 - 8*8`，`fy = gy + row*16*8 + 15*8 - 23*8`。
  - 断言精灵脚点 `(fx+8*8, fy+23*8)` 等于地砖脚点 `(gx+col*16*8+8*8, gy+row*16*8+15*8)`。
- 生成后断言精灵与地砖脚点一致、且都在画布范围内。

## 运行

```sh
python3 generate.py
```

仅依赖 Python 标准库；PNG 每行使用 filter 0，压缩级别 9。写到磁盘前会把同一像素数组编码两次并比较字节，确保可复现。

## 校验摘要（写入 `verification.json`）

- 帧顺序、帧尺寸 16×24、地砖尺寸 16×16。
- 调色板键严格等于 12 色 + `.`；不透明色 alpha 均为 255。
- 锚点像素不透明，且与身体 4-连通。
- 地砖全不透明。
- 精灵脚点 == 地砖脚点；角色与地砖边界均有效。
- 生成字节可复现（两次编码结果相同）。
- 不断言左右帧镜像相等。

## 局限

- 探索性样本；未获作者批准。
- 未做游戏内玩法验证（移动、碰撞、动画等均未测试）。
- `left` / `right` 为独立帧，观感一致性仅凭人工观看，不由断言保证。
