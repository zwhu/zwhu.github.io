## 基准审阅：保持与修正

| 项目 | 必须保持的视觉特征 | 允许修正及验收证据 |
| --- | --- | --- |
| 主角头部 | 蓬松、不对称的黑发轮廓；暖肤色、简化眼鼻；较大的头与同一头身比；无眼镜 | 将细碎纹理改为清楚的离散色块；四向对照原图，不能改成小头或仅有两点的通用角色 |
| 主角服装 | 敞开的朱砂红外套、浅色内衫、深灰裤、浅色鞋与深色边缘；前后衣服关系一致 | 固定描边与像素颗粒，不删掉衣襟、袖口、鞋的识别细节 |
| CTO | 方框眼镜、灰蓝衣服、挂绳与胸前牌；与主角共用身体尺度与脸部画法 | 不用颜色替换主角直接冒充 CTO；造型是设定，不还原真人 |
| 同事 | 深色短发、低饱和草绿衣服、手持杯子的姿态；坐着的同事有椅背与背向轮廓 | 同一画法与描边；后续分别制作所需姿态，不把缺失方向写为通过 |
| 场景 | 正交俯视三分之四、轴向木地板、深色结构边框；桌椅与人物比例、书脊与文具等生活细节 | 消除混合像素大小、细腻木纹、柔焦与渐变；仍保留物件种类、层次和细节密度 |
| UI | 暖白细边框、少量红色提示；示例中的头像与人物一致 | 正式中文用 HTML/CSS，不烧入图像；菜单选中项、焦点与手机布局另作实际验收 |

基准角色栏提供正面、一侧和背面，没有完整左右两侧、四向动画或统一生产锚点。不能直接切图声称四向图集齐备。规格中的 16×16 图块、约 16×24 角色仍是起点；若该尺寸无法容纳基准特征，先通过较高分辨率样品比较并记录参数，不默默简化人物。

第一份请求为 [NJ-CHAR-001](./requests/NJ-CHAR-001.json)：仅制作主角四向静止样品，先核对造型与尺度。它不替代 NPC、办公室分层素材、动画和 HTML UI 的后续制作。
