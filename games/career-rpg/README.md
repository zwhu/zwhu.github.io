# 一路写来

博客仓库内的独立像素 RPG 子项目。通过合肥、南京、杭州的经历呈现作者做事方法的变化，技术方向为 Three.js 加简单引擎。

南京完整样章已实现并合并，包含七状态主线、存档、四向行走、NPC、情绪、坐姿打字、五工位与头部气泡；键盘、阅读和回退已有定点修复与独立证据，完整场景尚未通过。走路卡顿未解决且暂停排查；loop和TraeX后台任务保持暂停。

当前采用[技术方案](./technical-plan.md)：image_gen制作人物/表情，程序制作可复用环境与处理图集，保留原图、输出压缩运行版本。面向桌面键盘游玩，浏览器作为现有开发入口；H5发布、移动端和弱网暂不实施，原生封装工具未定。最新进度见[交接说明](./handoff.md)，启动说明见 [Web README](./web/README.md)。
