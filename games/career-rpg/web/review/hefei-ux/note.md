# 合肥章实拍

Chrome headless，1400×1100，软件 WebGL。地址 `games/career-rpg/web/?chapter=hefei`。脚本 `games/career-rpg/web/tests/hefei-ux-capture.mjs` 用键盘走路、按 E 和确认键走完整章，每步截游戏画面，并把对白、任务条、按钮、箭头目标写入 `checks.json`。全程按钮和页面正文都没有「回看」。打开着的对话都贴在画面底部。

## 步骤与画面文案

1. 进章。旁白，没有箭头：「面试。原本录用的人嫌工资低，没来。」任务条：「面试：从门口走到老板桌前」。`01-interview-narration.png`
2. 走到长桌对面靠自己工位的同事（147, 192）。箭头在这位同事头上：「你是来面试的吧？别在这儿站着，老板在右边茶桌等你。」`02-colleague-near-interview.png`
3. 走到靠里的同事（215, 192）。箭头在他头上：「招人的事别问我，找老板。他在茶桌那边坐着。」`03-colleague-far-interview.png`
4. 去左边书架（24, 90）。书的图标没亮，也不能拿走。旁白，没有箭头：「现在先去找老板面试。」`04-shelf-interview.png`
5. 走到老板面前直接开谈，没有「老板在茶桌旁」。箭头在老板头上（画面坐标对应世界 x≈325，老板站在 326）：「你能力不行，来了也干不了活。」`05-boss-line.png`
6. 我，箭头在玩家头上：「我不要工资，让我来试试就行。」`06-player-line.png`
7. 老板，箭头仍在老板头上：「行，那你想试试我也不拦你，反正不要工资，到时候你自己也会受不了就走。」`07-boss-reply.png`
8. 收束。旁白，没有箭头：「就这样留下了。」任务条同时变成「白天：去自己的工位开始干活」。书架上的《锋利的 jQuery》这时才亮。`08-stayed.png`
9. 这句话说完，底部对话收起，任务条留着白天那句。`09-day-taskbar.png`
10. 白天再找两位同事，只是闲话，没有学习按钮。近的：「好饿啊，搞完这点要不去吃面？」里的：「没事，熬过星期三就是星期五。」`10-colleague-near-day.png`、`11-colleague-far-day.png`
11. 自己的工位（75, 192）接任务：「我在自己的工位坐下，接过电脑上的任务。」`12-take-task.png`
12. 还是这台电脑，不是同事工位。箭头在玩家头上：「第一次用 Linux 开发机，第一次用 Git。不会的就 Google。」`13-linux.png`
13. 回到左边书架。旁白：「书架上夹着一本《锋利的 jQuery》。」`14-jquery-found.png` 拿下来：「第一次写前端，手边是《锋利的 jQuery》。还第一次写了 E2E 测试。」`15-jquery-learn.png`
14. 白天两项做完。旁白，画面转夜，没有箭头：「白天的活告一段落。天黑了，我还没走。」任务条：「深夜 0/2 · 自己工位上看 Java，还有数据库和 NoSQL」。`16-night-falls.png`
15. 夜里仍在自己工位。Java：「晚上对着 Java 往下啃。」`17-java.png` 数据库和 NoSQL：「再学数据库和 NoSQL。」`18-db.png` 交互点分别是 (75, 192) 和 (84, 192)。
16. 旁白：「日夜颠倒地学新东西，拼命把活干好，争取能留下来。」`19-days-pass.png`
17. 接着旁白，没有箭头：「入职两个月，加了两次薪。」`20-raise-narration.png`
18. 走到老板桌前。箭头在老板头上，没有回看：「努力工作的人一定会被看到的。」`21-boss-raise.png`
