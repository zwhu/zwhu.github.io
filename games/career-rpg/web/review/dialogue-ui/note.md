# 对话窗

三章共用画面底部的米色对话窗，落在黑色场景框里面。填充 `rgba(249, 248, 241, 0.8)`，双线墨色边。短句时逻辑尺寸为 x=8、宽 368、高 54、距画布底 4。有剧情选项时窗口向上加高，底边距不变。

旁白不显示名牌、头像、红箭头，也不显示「旁白」。角色说话时，名牌用场景里的名字（老板 / 同事 / 我），红箭头仍在说话人头顶。右下角 ▼ 约每秒闪一次；只有这一项可确认时，Enter 收起对话。键盘焦点在 ▼ 上时，箭头下方有一条短红线。

「继续探索」和「Shift+Tab 读正文 · PgUp/PgDn 翻页 · Home/End 首尾」已从对话窗去掉。剧情选项仍用原句，例如老板那句下面的「我不要工资，让我来试试就行。」
