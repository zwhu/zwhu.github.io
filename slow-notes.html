用 HTML 搭一个足够简单的个人博客

2026-10-27   ·   Web · HTML   ·   示例文章

这个示例从最小的目录开始：首页负责列出文章，每篇文章都是独立的 HTML 文件，共用一份样式。

先把结构定下来

暂时不需要构建工具。页面数量少的时候，直接维护静态文件容易理解，也方便定位问题。

index.html
style.css
posts/
  hello-world.html
.nojekyll

使用相对路径

首页引用样式时可以写成 ./style.css。位于 posts/ 的文章页面，需要使用 ../style.css 返回上一层。

<!-- posts/hello-world.html -->
<link rel="stylesheet" href="../style.css">
<a href="../index.html">返回首页</a>

这样放到域名根目录或项目子目录时，都能保持文件之间的相对关系。

什么时候需要自动生成

如果每次发文章都要改很多重复内容，或者开始需要标签、分页和全文检索，再引入生成工具会更合适。
